# Form submission states

Represent submission state explicitly so users understand what is happening.

- **Idle:** no submission is in progress.
- **Invalid:** one or more fields need correction.
- **Submitting:** prevent accidental duplicate submissions and show progress.
- **Success:** confirm completion and describe the next step.
- **Failure:** preserve entered data and provide a recovery action.

Make status updates accessible to assistive technology and avoid relying on colour alone.
