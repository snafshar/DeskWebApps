# Keyboard navigation review

- [ ] Every interactive control can be reached with Tab and Shift+Tab.
- [ ] Focus order follows the visual and task order.
- [ ] Focus indicator is clearly visible.
- [ ] Dialogs keep focus inside while open and restore it when closed.
- [ ] Escape closes dismissible overlays where expected.
- [ ] Form errors are announced and associated with the relevant fields.
- [ ] No keyboard trap exists in the primary workflow.
