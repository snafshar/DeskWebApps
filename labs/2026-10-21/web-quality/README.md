# Web Quality Toolkit

Practical review resources for small React and TypeScript applications.

## Before a release
1. Review `accessibility-review.md`.
2. Test loading, empty, success, and failure states.
3. Check API errors and avoid exposing secrets in client bundles.
4. Verify that each user can access only their own records.
5. Test responsive layouts and keyboard-only interaction.
6. Record known limitations in the release notes.
