# Web Accessibility Review

- [ ] All functionality is available by keyboard.
- [ ] Focus order follows the visual and reading order.
- [ ] Focus indicators are visible.
- [ ] Form controls have persistent labels and useful error text.
- [ ] Headings describe the page structure.
- [ ] Images have appropriate alternative text (or empty alt for decorative images).
- [ ] Text contrast is checked against WCAG requirements.
- [ ] Zoom and narrow viewport layouts remain usable.
- [ ] Reduced-motion preferences are respected.
- [ ] Status changes are announced when needed.

Automated checks help, but do not replace keyboard and screen-reader testing.
