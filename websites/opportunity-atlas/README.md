# Opportunity Atlas

I designed and implemented Opportunity Atlas as an interactive research-opportunity dashboard. It helps users filter funded computer science positions across Northern Europe and build a shortlist.

## What I built

- Responsive, accessible single-page interface
- Search and filtering by country and research field
- Interactive shortlist state
- Realistic sample dataset with clear prototype disclosure
- Recruiter-ready product design and documentation

## Technology

Next.js-compatible React, TypeScript, CSS, and Vinext for Cloudflare deployment.

## Run locally

```bash
npm install
npm run dev
```

This is a portfolio prototype using sample data. A production version would connect to verified university feeds and add persistent user accounts.
